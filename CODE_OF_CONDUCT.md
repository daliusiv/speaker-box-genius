# Code of Conduct

Speaker Box Genius is a hobby community project. Everyone is welcome, from first-time box builders to professional acousticians.

**Expected:**
- Be respectful and patient, especially with beginners. Everyone started somewhere.
- Critique designs, data and code, not people.
- Back up technical claims with measurements, maths or sources where you can.

**Not acceptable:**
- Harassment, insults, or discriminatory language of any kind
- Personal attacks or deliberate intimidation
- Spam, or promoting commercial products in issues and PRs

The maintainers may edit or remove comments, close issues, or block users who break these rules. To report a problem privately, contact the maintainer through their GitHub profile.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
